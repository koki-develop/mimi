# src-tauri

Rust backend for the Tauri shell. See `../CLAUDE.md` for the high-level data flow and top-level commands.

## Commands

- `cargo check --manifest-path src-tauri/Cargo.toml` / `cargo test --manifest-path src-tauri/Cargo.toml` — always use `--manifest-path` instead of `cd src-tauri && cargo ...`. The compound form breaks Claude Code's per-subcommand permission matching and triggers an approval prompt every time.

## Module layout

- `src/lib.rs` — thin entry point (~20 lines). Builds the Tauri app, wires the plugins, installs `AppState`, registers command handlers.
- `src/main.rs` — calls `app_lib::run()`. Standard Tauri boilerplate.
- `src/config.rs` — `Config::from_env()` reads the `MIMI_*` env vars and applies clamps.
- `src/app/` — daemon lifecycle + IPC (the `#[tauri::command]` handlers, `AppState`, the `Daemon` struct + stdout reader task in `daemon.rs`). See `@src/app/CLAUDE.md`.
- `src/summarizer/` — timeline-summary pipeline (Ollama client, prompt assembly, periodic loop, event emitter). See `@src/summarizer/CLAUDE.md`.

## Sidecar bundling

- `tauri.conf.json` declares `"externalBin": ["binaries/transcribe"]`. Tauri resolves this to `binaries/transcribe-<target-triple>` at build time — the Makefile copies to that exact filename. `binaries/` is git-ignored and regenerated by `make sidecar`.
- The sidecar is launched via `tauri-plugin-shell`'s `sidecar("transcribe")`. Requires `tauri-plugin-shell` registered in `lib.rs` AND a capability allowing it (currently `core:default`; Tauri 2 accepts sidecar spawn without an explicit shell capability when declared as `externalBin`).
